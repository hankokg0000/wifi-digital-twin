# บทเดโม: ตรวจจับคนผ่านผนังด้วย WiFi

ใช้ hotspot มือถือเป็น **Transmitter** และ Mac เป็น **Receiver** เมื่อคนเดินผ่านเส้นสัญญาณ แอปจะขึ้น "มีการเคลื่อนไหว" ห้องนอนแขกใน twin เรืองป้าย "ของจริง" และมี Alert ของจริงขึ้นใน feed

---

## 1. จัดอุปกรณ์

```
   [ hotspot มือถือ ]  ← นอกห้อง / หลังผนัง
          │
   ═══════╪═══════  ผนัง
          │   ← เส้นสัญญาณ (ให้คนเดินตัดเส้นนี้)
          │
     [ Mac บนโต๊ะ ]
```

- **ระยะ:** hotspot กับ Mac ห่างกัน 3–5 m มีผนังหรือประตูปิดคั่น 1 ชั้น
- **ความสูง:** วางทั้งสองเครื่องที่ระดับโต๊ะ (~0.8–1 m) เพราะเป็นระดับลำตัวคน
- **ที่นั่งผู้ชม:** เส้นสัญญาณ**ต้องไม่ผ่านที่นั่งใคร** คนนั่งขยับตัวก็ทำให้สัญญาณแกว่ง
- **hotspot:** เปิดค้างไว้ เสียบสายชาร์จ และปิดโหมดประหยัดพลังงานของมือถือ
- **Mac:** ต้องต่อ hotspot อยู่ **ไม่ใช่ WiFi ออฟฟิศ** (Mac ชอบสลับกลับไปต่อ WiFi ออฟฟิศเอง ให้เช็กที่ไอคอน WiFi ก่อนเริ่มทุกครั้ง)

## 2. ก่อนเริ่ม 10 นาที

1. เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่งนี้ จากนั้นเปิด http://localhost:5173

   ```bash
   pnpm dev
   ```

2. เช็กแผง **ตรวจจับ WiFi** ต้องขึ้น "เชื่อมต่อแล้ว" พร้อมค่า dBm ถ้าขึ้น "โหมดจำลอง" แปลว่าไม่ได้อ่านจากเครื่องจริง
3. ช่อง "ห้องที่เฝ้า" ต้องเป็น **ห้องนอนแขก**
4. ให้ทุกคนนั่งประจำที่ ไม่มีใครเดินผ่านเส้น แล้วกด **อัด Baseline (30 วิ)**
5. ทดลองเดินผ่านเส้น 1 รอบ ต้องขึ้น "มีการเคลื่อนไหว" ภายในไม่กี่วินาที
6. เปิดไฟล์ Recording สำรองเตรียมไว้ใน Finder แต่ยังไม่ต้องโหลดเข้าแอป

## 3. บทพูด (~5 นาที)

| เวลา | ทำอะไร | พูดว่า |
|---|---|---|
| 0:00 | กด **เริ่มเดโม** | "นี่คือ digital twin ของบ้าน 2 ชั้น มีคนและสัตว์จำลองเดินอยู่ ระบบรู้ว่าใครอยู่ห้องไหน" |
| 0:40 | ชี้ heatmap และ hover ที่ห้อง | "สีบนพื้นคือความแรงสัญญาณ WiFi ที่คำนวณจากผนังและเฟอร์นิเจอร์จริง คนเดินบังก็เห็นสัญญาณเปลี่ยน" |
| 1:20 | ชี้ Alert บุกรุก/ล้ม | "ตั้งพื้นที่ห้ามเข้าได้ คนล้มก็แจ้งเตือนทันที ตอนนี้ยังเป็นข้อมูลจำลอง" |
| 2:00 | ชี้แผง **ตรวจจับ WiFi** | "ส่วนนี้คือของจริง Mac เครื่องนี้กำลังอ่านสัญญาณจากมือถือที่อยู่หลังผนัง ไม่มีกล้อง และคนไม่ต้องพกอะไร" |
| 2:30 | ทุกคนนั่งนิ่ง | "ตอนนี้ไม่มีใครเดิน สถานะคือ **ไม่มีการเคลื่อนไหว**" |
| 2:50 | ให้คนหนึ่งเดินผ่านเส้นไป-กลับ | "พอมีคนเดินผ่าน สัญญาณที่ทะลุผนังมาจะแกว่ง ระบบจับได้ ห้องนอนแขกใน twin เรือง และมี Alert **ของจริง** ขึ้น" |
| 3:40 | กดตัวกรอง **ของจริง** ใน feed | "แยกดูได้ว่าแจ้งเตือนไหนมาจากเซนเซอร์จริง ไหนมาจากการจำลอง" |
| 4:10 | สรุป | "เหมาะกับห้องที่ห้ามติดกล้อง เช่น ห้องนอน ห้องน้ำ ขั้นต่อไปคือใช้หลายเส้นสัญญาณเพื่อบอกตำแหน่ง และตรวจการล้มด้วย WiFi" |

**ประโยคที่ต้องพูดให้ถูก:**
- ✅ "ไม่มีการเคลื่อนไหว" ❌ ห้ามพูดว่า "ห้องว่าง" เพราะคนนอนนิ่งหรือล้มอยู่ ระบบก็มองไม่เห็น
- ✅ "บอกได้ว่ามีการเคลื่อนไหว" ❌ อย่าพูดว่า "เห็นคนหลังผนัง" หรือ "รู้ว่าเป็นใคร" เพราะระบบแยกคนกับสัตว์ไม่ได้และยังไม่บอกตำแหน่ง

## 4. ถ้าของจริงไม่ทำงาน

| อาการ | แก้ |
|---|---|
| ขึ้น "ไม่ได้เชื่อมต่อ" | เช็กว่า Mac ยังต่อ hotspot อยู่ แล้วรีโหลดหน้า |
| ขึ้น "มีการเคลื่อนไหว" ค้างทั้งที่ไม่มีใครเดิน | มีคนขยับในแนวเส้นสัญญาณ ให้ย้ายที่นั่งออก แล้วอัด Baseline ใหม่ |
| เดินแล้วไม่ขึ้น | เดินให้ตัดเส้นตรงกลาง ช้าๆ ไป-กลับ 2–3 รอบ หรือขยับ hotspot ให้ใกล้ขึ้น |
| ยังไม่ได้ภายใน 1 นาที | กด **เปิด Recording** แล้วเลือกไฟล์สำรอง และพูดตรงๆ ว่า "นี่คือผลที่อัดไว้เมื่อวาน" (จอจะขึ้นป้าย **ย้อนหลัง** เอง) |

## 5. ซ้อมคืนนี้

**รอบ 1 (~15 นาที):** ใช้หาค่าตัวตรวจจับที่เหมาะ
1. จัดอุปกรณ์ตามข้อ 1 ที่บ้าน
2. กด **เริ่มอัด Recording**
3. ห้องว่าง ไม่มีคนเดิน 60 วินาที
4. เดินตัดเส้นไป-กลับ 30 วินาที แล้วออกนอกเส้น 30 วินาที ทำซ้ำ 3 รอบ
5. นั่งนิ่งข้างเส้น 60 วินาที
6. กด **หยุดและบันทึก** แล้วส่งไฟล์ให้ Claude ปรับค่า

**รอบ 2 (~15 นาที):** ซ้อมจริงและอัดไฟล์สำรอง
1. ซ้อมเต็มบทตามข้อ 2–3
2. อัด Recording ช่วงเดินโชว์ เก็บไว้เป็นไฟล์สำรอง
3. อัดหน้าจอด้วย QuickTime (File → New Screen Recording) เก็บไว้อีกชั้น
